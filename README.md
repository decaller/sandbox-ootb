# Sandbox and Out of the Box - Pembelajaran Alamiyah Mustaqbal Way

Presentasi interaktif berbasis [Reveal.js](https://revealjs.com/) mengenai konsep **Sandbox** dan **Out of the Box (OOTB)** dalam metodologi Pembelajaran Alamiyah.

🌐 **Live Presentation**: [https://decaller.github.io/sandbox-ootb/](https://decaller.github.io/sandbox-ootb/)

---

## 📑 Struktur Slide Presentasi

1. **Cover**: *Sandbox and Out of the Box - Pembelajaran Alamiyah Mustaqbal Way*
2. **Understand**: *WHAT IS TO... UNDERSTAND ?*
3. **Gemini Conversation**: Sesi eksplorasi konsep sandbox vs out-of-the-box
4. **Laboratorium Visual**: Simulasi interaktif perbandingan luas geometri vs partisi pias integral
5. **Pola**: Diagram Siklus Geometri
6. **Pola Yang Dibutuhkan**: Diagram Funnel Filter (Agama, Lingkungan, Pemerintah, Masa Depan)
7. **Sandbox vs Out of the Box**: Pemetaan siklus pembelajaran
8. **Perencanaan**: Rencana tahapan Pertemuan 1 s.d. 4
9. **Tahap SD & SMK**: Studi komparasi (Terrarium, Game Puzzle, Kebun, How Computer Works)
10. **Tahap Sandbox & OOTB**: Matriks Sifat & Bahan/Alat (Panduan Guru, Lembar Kerja, Akses Lingkungan)
11. **Observasi & Dokumentasi Progress Murid**: Rubrik Asesmen Sumatif & Kriteria
12. **Saatnya Berbelok**: Evaluasi personalisasi & kondisi pembelajaran
13. **Takeaway**: *Mengembalikan firasat dalam pendidikan*
14. **Implementasi Insan Taqwa**: Pilar Luar (Parenting, Kontribusi PKN) & Dalam (Bahasa Hati, Kemudahan, Jabatan, Wake Up Call, Apresiasi Terarah, Pelatihan)
15. **Alhamdulillah**: Penutup (*Anti System System Club*)

## 🛠️ Menjalankan Secara Lokal

Prasyarat: [Node.js](https://nodejs.org/) (v16+)

```bash
# Pindah ke folder reveal.js
cd reveal.js

# Install dependensi
npm install

# Jalankan development server
npm start
```

Buka browser di `http://localhost:8001/` (atau port yang ditampilkan di terminal).
